# Trainingsprogramme verwenden

Mit Trainingsprogrammen legen Trainer fest, welche Trainingsmodule die Teilnehmer absolvieren sollen.

Es gibt zwei Arten von Trainingsprogrammen:

- **Beliebige Reihenfolge** – Die Teilnehmer können die ausgewählten Module in beliebiger Reihenfolge absolvieren.
- **Lehrplan** – Die Teilnehmer müssen die Module in der vom Trainer festgelegten Reihenfolge absolvieren.

Trainingsprogramme werden im **Training Workx-Portal** verwaltet.

Sie erreichen das Portal unter:

- Logistic Workx: portal.logisticworkx.com
- Cleaning Workx: portal.cleaningworkx.com

---

## Ein Trainingsprogramm erstellen

1. Melden Sie sich im **Training Workx-Portal** an.
2. Gehen Sie zu **Training → Trainings**.
3. Klicken Sie auf **+ Trainingsprogramm**.
![Trainingsübersicht](../assets/lessonplan.png)
4. Geben Sie einen Namen für das Trainingsprogramm ein.
5. Wählen Sie die gewünschte **Trainingsform**:
   - **Beliebige Reihenfolge** – Die Teilnehmer können die ausgewählten Module in beliebiger Reihenfolge absolvieren.
   - **Lehrplan** – Die Teilnehmer müssen die Module in der festgelegten Reihenfolge absolvieren.
![Auswahl der Trainingsform](../assets/edit-lessonplan.png)
6. Fügen Sie die Module hinzu, die Sie aufnehmen möchten.
![Module hinzufügen](../assets/add-modules.png)
7. Speichern Sie das Trainingsprogramm.



---

## Ein Trainingsprogramm zuweisen

Sobald ein Trainingsprogramm erstellt wurde, kann es einzelnen Teilnehmern zugewiesen werden.

1. Gehen Sie zu **Training → Teilnehmer**.
2. Suchen Sie den Teilnehmer und klicken Sie auf **Module anzeigen**.
![Module anzeigen](../assets/view-modules.png)
3. Klicken Sie auf **Module verwalten**.
![Module verwalten](../assets/manage-modules.png)
4. Wählen Sie oben rechts im Dropdown-Menü **Trainingsprogramm** das erstellte Trainingsprogramm aus.
![Module auswählen](../assets/select-program.png)
5. Speichern Sie die Änderungen.

Das ausgewählte Trainingsprogramm ist jetzt dem Teilnehmer zugewiesen.

---

## Trainingsprogramme in VR verwenden

Wenn Teilnehmer das VR-Training starten, sehen sie die Module aus dem ihnen zugewiesenen Trainingsprogramm.

- Wenn das Trainingsprogramm auf **Beliebige Reihenfolge** eingestellt ist, können die Teilnehmer die Module in beliebiger Reihenfolge absolvieren.
- Wenn das Trainingsprogramm ein **Lehrplan** ist, müssen die Teilnehmer die Module in der festgelegten Reihenfolge absolvieren.
