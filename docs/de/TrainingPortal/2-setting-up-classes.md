# Klassen einrichten

Mit Klassen können mehrere Teilnehmer mit demselben VR-Headset trainieren.  
Teilnehmer derselben Klasse können während des Trainings zwischen Benutzern wechseln.

Klassen werden im **Training Workx-Portal** angelegt und verwaltet.

Sie erreichen das Portal unter:

- Logistic Workx: portal.logisticworkx.com  
- Cleaning Workx: portal.cleaningworkx.com  

---

## Eine Klasse anlegen

1. Melden Sie sich im **Training Workx-Portal** an.  
2. Gehen Sie zu **Training → Klassen**.  
3. Klicken Sie auf **Neue Klasse**.  
4. Geben Sie einen Namen für die Klasse ein.  
5. Wählen Sie die Teilnehmer aus, die zu dieser Klasse gehören.  
6. Speichern Sie die Klasse.  

Wählen Sie einen eindeutigen Namen, damit Trainer die richtige Klasse leicht erkennen können.

![Teilnehmer für Klasse auswählen](../assets/selecting-students-for-class.png)

---

## Eine Klasse einem Headset zuweisen

Damit Teilnehmer einer Klasse mit einem Headset trainieren können, muss das Headset mit dieser Klasse verknüpft sein.

1. Gehen Sie zu **Training → Geräte**.  
2. Wählen Sie das Headset aus, das Sie verwenden möchten.  
3. Wählen Sie die Klasse aus, die mit diesem Headset trainieren soll.  
4. Speichern Sie die Änderungen.  

![Klasse für Headset auswählen](../assets/select-class.png)

---

## Teilnehmer während des Trainings wechseln

Sobald ein Headset mit einer Klasse verknüpft ist, können Teilnehmer im VR-Training den Benutzer wechseln.

Dies ist über das **Teilnehmerfeld neben dem Modulauswahlbildschirm** möglich.

![Teilnehmer in VR wechseln](../assets/change-student-in-vr.png)
