# Module auswählen

Wenn Sie das Training starten, beginnen Sie immer in unserer Trainingslobby. Die Lobby sieht aus wie ein Büro in Shanghai, in dem sich vor Ihnen ein großer Bildschirm befindet. In diesem Menü wählen Sie aus, welches Modul Sie spielen möchten.

---

## 1. Das Training auswählen

Wenn Sie ein Gerät mit mehreren Trainings verwenden (zum Beispiel Sofia VR und Tom VR), müssen Sie zuerst auswählen, welches Training Sie spielen möchten. Dazu berühren Sie die Schaltfläche des Trainings mit Ihrer Hand.

Wenn Sie später zu einem anderen Training wechseln möchten, berühren Sie mit Ihrer Hand den Trainingskopf oben links auf dem Bildschirm.

![Training auswählen](../assets/select-training.png)

---

## 2. Das Modul auswählen

Nachdem Sie das Training ausgewählt haben, können Sie das Modul auswählen, das Sie trainieren möchten. Wählen Sie das Modul aus, indem Sie es mit Ihrer Hand berühren.

Wenn Sie zu einem anderen Modul zurückwechseln möchten, können Sie den Pfeil unten auf dem Bildschirm verwenden.

![Modul auswählen](../assets/select-module.png)

---

## 3. Den Trainingsmodus auswählen

Bei den meisten Modulen können Sie einen Übungsmodus und ein Erkennungsspiel spielen. Nachdem Sie ein Modul ausgewählt haben, entscheiden Sie, welches davon Sie spielen möchten. Im Übungsmodul lernt der Teilnehmer etwas Neues, während ein Erkennungsspiel oder eine Prüfung testet, ob der Teilnehmer etwas selbstständig kann.

![Modus auswählen](../assets/change-mode.png)
