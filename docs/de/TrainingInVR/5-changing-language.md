# Die Sprache ändern

Das VR-Training unterstützt mehrere Sprachen. Sie können die Sprache vor dem Start eines Trainingsmoduls ändern. Über den Spectator kann die Sprache auch während des Trainings geändert werden.

Die ausgewählte Sprache wird für die Anweisungen, die Sprachansagen und die Oberfläche im Training verwendet.

---

## Die Sprache in VR ändern

1. Starten Sie das VR-Training.  
2. Sie beginnen in der **Lobby**.  
3. Wählen Sie auf dem Whiteboard die Option **Sprache ändern**.  
4. Wählen Sie die gewünschte Sprache.  

Das Training wird jetzt in der ausgewählten Sprache fortgesetzt.

![Sprache in VR ändern](../assets/change-language.png)

---

## Die Sprache über den Spectator ändern

Trainer können die Sprache auch über den **Spectator** ändern.

1. Öffnen Sie den Spectator.  
2. Verbinden Sie sich mit dem VR-Headset.  
3. Öffnen Sie in den Steuerelementen die Option **Einstellungen > Sprache**.  
4. Wählen Sie, ob Sie die Sprache des Spectators oder des Teilnehmers ändern möchten (die Spectator-Sprache ist die Sprache auf dem Koffer, die Teilnehmersprache ist die Sprache im Headset).  
5. Wählen Sie die gewünschte Sprache.  

![Spracheinstellungen im Spectator](../assets/spectator-languages.png)

---

Die Sprache wird sofort aktualisiert.
