# Den Koffer starten

Mit diesem Koffer bleiben Sie ganz einfach auf dem neuesten Stand, sehen, was der Teilnehmer in VR macht, und können so schnell wie möglich mit dem Training beginnen. Das Starten des Koffers ist ganz einfach.

---

## 1. Den Koffer anschließen

Stecken Sie den Koffer in eine Steckdose. Dadurch schalten sich der Koffer und der Bildschirm automatisch ein. Der Start dauert etwa 2 Minuten.

![Koffer angeschlossen](../assets/box-plugged-in.png)

---

## 2. Optional: Einen Bildschirm anschließen

Wenn Sie möchten, können Sie jetzt mit dem HDMI-Kabel im Koffer einen Bildschirm anschließen. Stecken Sie das Kabel einfach in die rechte Ecke des Koffers. Der Bildschirm wird automatisch verbunden, wenn Sie den Spectator starten.

![HDMI-Eingang leer](../assets/hdmi-empty.jpeg)

![HDMI eingesteckt](../assets/hdmi-pluggedin.jpeg)

---

## 3. Das Headset einschalten

Während Sie warten, bis der Koffer gestartet ist, können Sie das Virtual-Reality-Headset einschalten, indem Sie die Ein-/Aus-Taste an der Seite gedrückt halten. Das Headset braucht einige Sekunden zum Starten. Danach können Sie das Headset aufsetzen.

![Headset einschalten](../assets/turn-on-headset.png)

---

## 4. Den Spectator starten

Sobald der Koffer gestartet ist, können Sie den Spectator starten, indem Sie auf dem Bildschirm des Koffers auf die Schaltfläche **Starten** tippen. Anschließend können Sie das Headset auswählen, das Sie beobachten möchten.

![Launcher](../assets/launcher.png)

---

## 5. Headset auswählen

Nachdem der Spectator gestartet ist, können Sie das Headset auswählen. Wählen Sie das Headset aus, das Sie beobachten möchten, und drücken Sie auf **Bestätigen**.

![Headset auswählen](../assets/spectator.png)

---

## 6. Verbinden

Ihr Koffer verbindet sich jetzt automatisch mit dem Headset, sobald dieses online ist. In der Zwischenzeit werden während des Ladens verschiedene Bilder angezeigt.

![Verbindungsbildschirm](../assets/spectator-connecting.png)

---

Der Koffer ist jetzt vollständig eingerichtet und einsatzbereit. Sie müssen nur noch das Headset aufsetzen und mit dem Training beginnen.

Weitere Informationen finden Sie unter [Ihren Koffer verwenden → Das VR-Headset verwenden](3-how-to-use-vr.md).
