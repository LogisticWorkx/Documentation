# Den Koffer ausschalten

Das Ausschalten des Koffers ist sehr einfach und dauert weniger als eine Minute. Denken Sie aber daran, alles wieder in den Koffer zu legen. So vermeiden Sie Probleme beim nächsten Start.

---

## 1. Das Netzkabel herausziehen

Ziehen Sie das Netzkabel des Koffers aus der Steckdose und legen Sie es zurück in den Koffer. Das ist jederzeit sicher möglich – Sie müssen sich keine Sorgen machen, dass Daten verloren gehen.

</div>

---

## 2. Das Headset ausschalten

Schalten Sie das Headset aus, indem Sie die Ein-/Aus-Taste an der Seite einige Sekunden gedrückt halten. Es ertönt ein Signalton und die Lichter erlöschen.

<div style="text-align:center">
    <img src="/../assets/turn-on-headset.png" width="500">
</div>

---

## 3. Einpacken und los

Sie können jetzt alles wieder einpacken und den Koffer schließen. Achten Sie darauf, dass keine Kabel im Deckel eingeklemmt werden. Schließen Sie alle 4 Sicherheitsverschlüsse, damit sich der Koffer nicht versehentlich öffnet.

Nachdem Sie den Koffer geschlossen haben, können Sie ihn überallhin mitnehmen.
