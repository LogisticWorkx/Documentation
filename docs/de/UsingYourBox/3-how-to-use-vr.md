# So verwenden Sie das VR-Headset

Vor Beginn des Trainings muss der Teilnehmer das VR-Headset und die Controller richtig verwenden.  
Befolgen Sie die folgenden Schritte für ein angenehmes und sicheres VR-Erlebnis.

---

## 1. Die Controller in die Hand nehmen

Nehmen Sie zuerst die Controller in die Hand, bevor Sie das VR-Headset aufsetzen.

1. Halten Sie in jeder Hand einen Controller.  
2. Stecken Sie Ihre Hände durch die Handschlaufen.  
3. Ziehen Sie die Schlaufen fest, damit die Controller sicher an Ihren Handgelenken bleiben.  

So können die Controller während des Trainings nicht herunterfallen.

![Controller halten](../assets/controller-hands.png)

---

## 2. Das VR-Headset aufsetzen

1. Drehen Sie das Rad an der Rückseite des Headsets, um das Kopfband zu lockern.  
2. Setzen Sie das Headset auf Ihren Kopf.  
3. Passen Sie die Position des Headsets an, bis das Bild scharf aussieht.  
4. Ziehen Sie das Rad an der Rückseite fest, bis das Headset bequem sitzt.  
5. Stellen Sie bei Bedarf das obere Band nach, damit das Headset stabil sitzt.  

![Headset anpassen](../assets/headstrap.png)

---

## 3. Das Bild einstellen

Für das beste Trainingserlebnis sollte das Bild scharf sein.

- Schieben Sie das Headset auf Ihrem Gesicht etwas nach oben oder unten.  
- Stellen Sie bei Bedarf die Bänder nach.  
- Achten Sie darauf, dass das Headset bequem, aber fest sitzt.  

Die schärfste Position kann bei jeder Person unterschiedlich sein.

---

## 4. Los geht's!

Sobald Headset und Controller richtig eingestellt sind, können Sie mit dem VR-Training beginnen.

Sie beginnen immer mit [Ihren Koffer verwenden → Den Spielbereich einrichten](4-guardian-setup.md).
