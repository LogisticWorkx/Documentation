# Ihren Koffer aktualisieren

Das System kann aktualisiert werden, um die neuesten Verbesserungen und Trainingsinhalte zu erhalten.

Updates werden über den **Launcher** verwaltet, der sich beim Start des Koffers automatisch öffnet.

---

## Das Update herunterladen

Bevor ein Update installiert werden kann, muss die neue Version zuerst **heruntergeladen** werden. Dieser Download erfolgt **automatisch im Hintergrund**, wenn der Koffer mit dem Internet verbunden ist.

Je nach Internetverbindung kann das Herunterladen des Updates **bis zu einer Stunde** dauern. Sie können das Update erst **nach Abschluss des Downloads** installieren.

## Das Update installieren

Sobald das Update heruntergeladen ist:

1. Klicken Sie im Launcher auf die Schaltfläche **Aktualisieren**.
2. Achten Sie darauf, dass das **VR-Headset eingeschaltet** ist.
3. Verbinden Sie das Headset mit dem **USB-C-Kabel im Koffer** mit dem Koffer.

<div style="text-align:center">
    <img src="/../assets/updating-3.png" width="500">
</div>

4. Drücken Sie auf **Aktualisieren**.

Das System aktualisiert sowohl das **VR-Headset** als auch die **Spectator-Software**.

---

## Installationsdauer

Die Installation des Updates dauert in der Regel **etwa 5 Minuten**.

Achten Sie darauf, dass das Headset während des Updates verbunden bleibt.
