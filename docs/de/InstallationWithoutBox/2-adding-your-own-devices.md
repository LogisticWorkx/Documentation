# Eigene Geräte hinzufügen

Wenn Sie Ihr eigenes VR-Headset statt eines von Training Workx bereitgestellten Headsets verwenden möchten, müssen Sie das Gerät zuerst im Portal registrieren. Nach der Registrierung können Sie die Trainingssoftware über den Launcher installieren.

---

## Wichtig

Ihr VR-Headset muss sich im **Entwicklermodus** befinden, damit die Installation funktioniert.


---

## Ein Gerät registrieren

1. Melden Sie sich im **Training Workx-Portal** an.
2. Gehen Sie zu **Training → Geräte**.
3. Klicken Sie auf **Eigenes Gerät registrieren**.
4. Fügen Sie das neue Headset hinzu.

Das Headset erscheint jetzt in Ihrer Geräteliste.

<img src="/../assets/registering-device.png" width="500">

---

## Die Software installieren

Nachdem Sie das Headset registriert haben, können Sie die Trainingssoftware installieren.

1. Schalten Sie das **VR-Headset** ein.
2. Verbinden Sie das Headset mit einem **USB-C-Kabel** mit Ihrem Computer.
3. Öffnen Sie den **Launcher**.
4. Gehen Sie zum Bereich **Aktualisieren**.
5. Klicken Sie auf **Aktualisieren**, um die Software zu installieren.

Die Installation kann einige Minuten dauern.

    <img src="/../assets/updating-2.png" style="width: 70%;">
</div>

---

## Das Headset identifizieren

Wenn die Installation abgeschlossen ist:

1. Setzen Sie das VR-Headset auf.
2. Starten Sie die Trainingsanwendung.
3. Sie sehen eine Liste nicht registrierter Headsets.
4. Wählen Sie den richtigen Namen für Ihr Gerät aus.

Das Headset ist jetzt mit Ihrem Konto verknüpft und für das Training einsatzbereit.
