# Ihr eigenes Headset aktualisieren

Das VR-Headset kann über den **Launcher** auf Ihrem Computer aktualisiert werden.  
Wenn Sie das Headset auf dem neuesten Stand halten, verfügen Sie immer über die neuesten Trainingsinhalte und Verbesserungen.

Über den Launcher können Sie sowohl das **Headset** als auch die **Spectator-Software** aktualisieren.

---

## Anleitung zum Aktualisieren

Das Aktualisieren Ihres eigenen Systems funktioniert genauso wie das Aktualisieren eines Training Workx-Koffers. Weitere Informationen finden Sie in dieser Anleitung: [Ihren Koffer verwenden > Ihren Koffer aktualisieren](../UsingYourBox/6-updating-your-box.md).
