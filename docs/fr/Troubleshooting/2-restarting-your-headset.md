# Redémarrer votre casque

Si le casque VR ne réagit pas correctement, un redémarrage permet souvent de résoudre le problème.  
Toutes les applications ouvertes sont alors fermées et le casque redémarre.

Le redémarrage **ne supprime aucune donnée ni aucune progression de formation**.

---

## Redémarrer depuis le casque

1. Mettez le **casque VR**.  
2. Maintenez enfoncé le **bouton d'alimentation** du casque.  
3. Un menu d'alimentation s'affiche.  
4. Sélectionnez **Redémarrer**.  
5. Attendez que le casque redémarre.  

Le casque s'éteint puis se rallume automatiquement.

![Redémarrer le casque](../assets/turn-on-headset.png)

---

## Redémarrer si le casque est bloqué

Si le casque ne répond pas :

1. Maintenez le **bouton d'alimentation** enfoncé pendant environ **10 secondes**.  
2. Le casque s'éteint.  
3. Appuyez de nouveau sur le **bouton d'alimentation** pour le rallumer.
