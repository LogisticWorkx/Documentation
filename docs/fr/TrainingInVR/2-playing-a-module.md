# Jouer un module

Lorsque vous commencez un module, vous êtes transporté dans une autre pièce. Dans cette pièce, un écran fixé au mur vous donne des instructions. Ces instructions sont également données oralement dans le casque.

---

## Écran d'instructions

L'écran d'instructions vous indique ce que vous devez faire pendant la formation. Si vous êtes bloqué, vous pouvez toujours revenir vers l'écran pour relire les instructions. Il peut aussi afficher des images pour vous aider à trouver la bonne direction.

Certains écrans d'instructions affichent également une barre de progression sous l'instruction. Elle vous indique où vous en êtes dans le module.

![Écran d'instructions](../assets/training-screen.png)

---

## Réaliser les étapes

Les instructions sont généralement aussi signalées par des surbrillances ou des flèches. Lorsque vous effectuez les bonnes actions, l'instruction suivante se lance automatiquement et l'écran d'instructions change.

![Réaliser les étapes](../assets/training-step.png)

---

## Écran des paramètres

Pour ouvrir l'écran des paramètres, touchez l'engrenage en haut à droite de l'écran d'instructions. Cet écran vous propose plusieurs options :

- Passer cette étape et aller à l'étape suivante  
- Fermer le module et revenir au lobby  
- Réécouter la dernière consigne vocale  

![Écran des paramètres](../assets/training-settings.png)
