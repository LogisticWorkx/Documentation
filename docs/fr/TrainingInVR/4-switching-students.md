# Changer de stagiaire

Pendant la formation, il est possible de passer d'un stagiaire à l'autre.  
Plusieurs stagiaires peuvent ainsi utiliser le même casque VR, tout en gardant chacun leur propre progression.

Les stagiaires sont gérés via le **portail en ligne** et peuvent ensuite être sélectionnés dans la formation.

---

## Sélectionner un stagiaire en VR

1. Lancez la formation VR.  
2. La formation commence dans le **lobby**.  
3. Sur la droite du tableau blanc, vous voyez le **panneau des stagiaires**.  
4. Sélectionnez le stagiaire que vous souhaitez former.  
5. Touchez **Appuyez pour confirmer**  

Le stagiaire sélectionné est maintenant actif pour la session de formation.

![Sélectionner un stagiaire](../assets/change-student.png)

Attention : lorsque vous changez de stagiaire, la langue passe à la **langue préférée** de ce stagiaire. La langue préférée peut être définie dans le **portail de formation**.

---

## Gérer les stagiaires en tant que formateur

Avant de pouvoir sélectionner des stagiaires en VR, le formateur doit les ajouter.

1. Accédez au **portail en ligne**.  
2. Ajoutez les stagiaires à la bonne **classe**.  
3. Sélectionnez la classe qui se forme sur le casque.  
   Voir [Configurer les classes](../TrainingPortal/1-setting-up-students.md).  

Une fois cette étape terminée, il est possible de changer de stagiaire dans la formation.

---

## Changer de stagiaire depuis le Spectator

Les formateurs peuvent également changer de stagiaire actif via le **Spectator**.

Le formateur peut ainsi changer de stagiaire sans interrompre la personne en VR.

![Changer de stagiaire dans le Spectator](../assets/spectator-sidebar-lobby.png)
