# Sélectionner des modules

Lorsque vous lancez la formation, vous arrivez toujours dans notre lobby de formation. Ce lobby ressemble à un bureau à Shanghai, avec un grand écran devant vous. Ce menu vous permet de choisir le module auquel vous souhaitez jouer.

---

## 1. Sélectionner la formation

Si vous utilisez un appareil proposant plusieurs formations (par exemple Sofia VR et Tom VR), vous devez d'abord choisir la formation à laquelle vous souhaitez jouer. Pour cela, touchez le bouton de la formation avec votre main.

Si vous souhaitez ensuite passer à une autre formation, touchez avec votre main la tête de la formation en haut à gauche de l'écran.

![Sélectionner la formation](../assets/select-training.png)

---

## 2. Sélectionner le module

Une fois la formation sélectionnée, vous pouvez choisir le module que vous souhaitez suivre. Sélectionnez le module en le touchant avec votre main.

Si vous souhaitez revenir à un autre module, utilisez la flèche en bas de l'écran.

![Sélectionner le module](../assets/select-module.png)

---

## 3. Sélectionner le mode de formation

La plupart des modules proposent un mode entraînement et un jeu de reconnaissance. Après avoir sélectionné un module, vous devez choisir l'un des deux. Le module d'entraînement apprend quelque chose au stagiaire, tandis qu'un jeu de reconnaissance ou un examen vérifie si le stagiaire sait le faire seul.

![Sélectionner le mode](../assets/change-mode.png)
