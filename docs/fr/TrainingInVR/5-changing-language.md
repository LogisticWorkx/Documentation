# Changer la langue

La formation VR est disponible en plusieurs langues. Vous pouvez changer la langue avant de lancer un module de formation. Le spectator peut également changer la langue pendant la formation.

La langue sélectionnée est utilisée pour les instructions, les consignes vocales et l'interface de la formation.

---

## Changer la langue en VR

1. Lancez la formation VR.  
2. Vous commencez dans le **lobby**.  
3. Sur le tableau blanc, sélectionnez l'option **Changer de langue**.  
4. Choisissez la langue que vous souhaitez utiliser.  

La formation se poursuit alors dans la langue sélectionnée.

![Changer la langue en VR](../assets/change-language.png)

---

## Changer la langue depuis le Spectator

Les formateurs peuvent également changer la langue depuis le **Spectator**.

1. Ouvrez le Spectator.  
2. Connectez-vous au casque VR.  
3. Dans les commandes, ouvrez l'option **Paramètres > Langue**.  
4. Choisissez si vous souhaitez changer la langue du Spectator ou celle du stagiaire (la langue du Spectator est celle de la valise, la langue du stagiaire est celle du casque).  
5. Sélectionnez la langue souhaitée.  

![Paramètres de langue du Spectator](../assets/spectator-languages.png)

---

La langue est mise à jour instantanément.
