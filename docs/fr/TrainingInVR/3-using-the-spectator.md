# Utiliser le Spectator

Le **Spectator** permet au formateur de voir ce qui se passe dans le casque VR et de gérer la session de formation.

Avec le Spectator, vous pouvez suivre le stagiaire en direct et piloter certaines parties de la formation depuis l'ordinateur.

---

## Lancer le Spectator

1. Démarrez le système et ouvrez le **Launcher**.  
2. Appuyez sur le bouton **Lancer le spectator**.  
3. L'application Spectator s'ouvre.  

Une liste des casques VR disponibles s'affiche.

![Launcher](../assets/launcher.png)

---

## Se connecter à un casque

1. Sélectionnez le casque que vous souhaitez suivre.  
2. Appuyez sur **Confirmer**.  

Une fois la connexion établie, l'écran affiche la **vue en direct du casque VR**.

![Vue du Spectator](../assets/spectator.png)

---

## Gérer la formation

L'interface du Spectator vous permet de piloter différentes parties de la formation.

Vous pouvez par exemple :

- Changer la **langue**  
- Changer de **stagiaire actif**  
- Ouvrir les **paramètres de formation**  

Le formateur peut ainsi guider la session de formation sans interrompre le stagiaire.

Dans le lobby, vous pouvez également **lancer des modules**.

![Commandes du Spectator dans le lobby](../assets/spectator-sidebar-lobby.png)

Dans un module, vous pouvez également **passer des étapes** et **fermer des modules**.

![Commandes du Spectator dans un module](../assets/spectator-sidebar.png)

---

## Afficher/masquer les commandes

Les boutons de l'interface sont visibles dans le lobby. Lorsque vous êtes dans un module, ils sont masqués par défaut.

- Pour masquer les boutons de l'interface : appuyez sur la **flèche dans le coin supérieur gauche** de l'écran.  
- Pour afficher les boutons de l'interface : il suffit de **toucher n'importe où sur l'écran**.  

---

## Modifier les paramètres

En appuyant sur le bouton des paramètres, vous ouvrez un menu proposant différentes options du spectator. Ces options sont enregistrées sur la valise : vous n'avez donc pas besoin de les régler à nouveau à chaque formation.

![Paramètres du Spectator](../assets/spectator-settings.png)
