# Consulter les résultats

Le portail Training Workx permet aux formateurs de consulter la progression et les résultats de chaque stagiaire.

Les résultats indiquent à quelle fréquence un stagiaire s'est formé, quels modules ont été terminés et quels scores ont été obtenus.

Vous pouvez accéder au portail à l'adresse suivante :

- Logistic Workx : portal.logisticworkx.com  
- Cleaning Workx : portal.cleaningworkx.com  

---

## Consulter la progression d'un stagiaire

1. Connectez-vous au **portail Training Workx**.  
2. Accédez à **Formation → Stagiaires**.  
3. Recherchez le stagiaire que vous souhaitez consulter.  
4. Cliquez sur **Voir les modules**.  

Vous voyez alors les modules que le stagiaire a terminés ainsi que sa progression actuelle.

![Voir les modules](../assets/view-modules.png)

---

## Consulter les résultats d'un module

Pour voir les résultats détaillés d'un module précis :

1. Ouvrez la liste des modules du stagiaire.  
2. Cliquez sur **Voir les résultats** pour le module.  

La page des résultats affiche :

- Le nombre de fois où le module a été joué  
- Le type de session (entraînement ou examen)  
- Le score obtenu  
- L'évolution de la progression du stagiaire au fil du temps  

![Résultats du module](../assets/view_results_page.png)

---

## Exporter les résultats

Si nécessaire, vous pouvez exporter les résultats pour une analyse plus approfondie.

1. Accédez à la page **Stagiaires**.  
2. Cliquez sur les 3 points à côté du bouton vert **Nouveau stagiaire**.  
3. Exportez les résultats sous forme de **fichier .csv**.  

Ce fichier peut être ouvert dans un tableur pour créer des rapports ou archiver les données.
