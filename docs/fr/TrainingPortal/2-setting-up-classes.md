# Configurer les classes

Les classes permettent à plusieurs stagiaires de se former avec le même casque VR.  
Les stagiaires d'une même classe peuvent passer d'un utilisateur à l'autre pendant la formation.

Les classes sont créées et gérées dans le **portail Training Workx**.

Vous pouvez accéder au portail à l'adresse suivante :

- Logistic Workx : portal.logisticworkx.com  
- Cleaning Workx : portal.cleaningworkx.com  

---

## Créer une classe

1. Connectez-vous au **portail Training Workx**.  
2. Accédez à **Formation → Classes**.  
3. Cliquez sur **Nouvelle classe**.  
4. Saisissez un nom pour la classe.  
5. Sélectionnez les stagiaires qui font partie de cette classe.  
6. Enregistrez la classe.  

Choisissez un nom clair pour que les formateurs puissent facilement identifier la bonne classe.

![Sélectionner les stagiaires de la classe](../assets/selecting-students-for-class.png)

---

## Attribuer une classe à un casque

Pour que les stagiaires d'une classe puissent se former sur un casque, ce casque doit être associé à cette classe.

1. Accédez à **Formation → Appareils**.  
2. Sélectionnez le casque que vous souhaitez utiliser.  
3. Choisissez la classe qui se formera sur ce casque.  
4. Enregistrez les modifications.  

![Sélectionner la classe du casque](../assets/select-class.png)

---

## Changer de stagiaire pendant la formation

Une fois un casque associé à une classe, les stagiaires peuvent changer d'utilisateur dans la formation VR.

Cela se fait depuis le **panneau des stagiaires, à côté de l'écran de sélection des modules**.

![Changer de stagiaire en VR](../assets/change-student-in-vr.png)
