# Utiliser les programmes de formation

Les programmes de formation permettent aux formateurs d'organiser les modules de formation que les stagiaires doivent terminer.

Il existe deux types de programmes de formation :

- **Ordre libre** – Les participants peuvent terminer les modules sélectionnés dans l'ordre de leur choix.
- **Plan de cours** – Les participants doivent terminer les modules dans l'ordre défini par le formateur.

Les programmes de formation sont gérés dans le **portail Training Workx**.

Vous pouvez accéder au portail à l'adresse suivante :

- Logistic Workx : portal.logisticworkx.com
- Cleaning Workx : portal.cleaningworkx.com

---

## Créer un programme de formation

1. Connectez-vous au **portail Training Workx**.
2. Accédez à **Formation → Formations**.
3. Cliquez sur **+ Programme de formation**.
![Aperçu des formations](../assets/lessonplan.png)
4. Saisissez un nom pour le programme de formation.
5. Choisissez le **Type de formation** souhaité :
   - **Ordre libre** – Les participants peuvent terminer les modules sélectionnés dans l'ordre de leur choix.
   - **Plan de cours** – Les participants doivent terminer les modules dans l'ordre prédéfini.
![Choix du type de formation](../assets/edit-lessonplan.png)
6. Ajoutez les modules que vous souhaitez inclure.
![Ajouter des modules](../assets/add-modules.png)
7. Enregistrez le programme de formation.



---

## Attribuer un programme de formation

Une fois créé, un programme de formation peut être attribué à des stagiaires individuels.

1. Accédez à **Formation → Stagiaires**.
2. Recherchez le stagiaire et cliquez sur **Voir les modules**.
![Voir les modules](../assets/view-modules.png)
3. Cliquez sur **Gérer les modules**.
![Gérer les modules](../assets/manage-modules.png)
4. En haut à droite, utilisez la liste déroulante **Programme de formation** pour sélectionner le programme de formation que vous avez créé.
![Sélectionner le programme](../assets/select-program.png)
5. Enregistrez les modifications.

Le programme de formation sélectionné est maintenant attribué au stagiaire.

---

## Utiliser les programmes de formation en VR

Lorsque les stagiaires lancent la formation VR, ils voient les modules de leur programme de formation attribué.

- Si le programme de formation est en **Ordre libre**, les stagiaires peuvent terminer les modules dans l'ordre de leur choix.
- Si le programme de formation est un **Plan de cours**, les stagiaires doivent terminer les modules dans l'ordre prédéfini.
